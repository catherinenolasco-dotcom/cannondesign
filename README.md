# Catherine Nolasco Portfolio (CannonDesign, Sr. Manager, HRIS & Operations)

An independent portfolio styled after the CannonDesign brand. Not affiliated with CannonDesign.

- `index.html` is the finished, self-contained page (fonts and headshot embedded).
- `src/` holds the content and build scripts. `content.py` and `portfolio_content.py` hold the text, `art_svgs.py` and `plan_art.py` hold the illustrations, and `build_portfolio.py` assembles the page.

To rebuild, place `headshot.jpg` and the Hanken Grotesk woff2 font files where `build_portfolio.py` expects them, then run `python3 src/build_portfolio.py`.

To publish with GitHub Pages: Settings, Pages, deploy from the `main` branch root.
